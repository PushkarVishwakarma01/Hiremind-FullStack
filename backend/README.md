# HireMind – Full Stack Job Platform

HireMind is a full-stack job portal that allows employers to post job opportunities and job seekers to explore available roles.  
The platform is built using **Spring Boot for the backend and React.js for the frontend**, with secure authentication using **Spring Security and JWT**.

---

## 🚀 Features

- Create, update, delete, and view job listings
- Keyword-based job search
- Secure authentication using **JWT**
- RESTful API architecture
- React frontend integrated with Spring Boot backend
- PostgreSQL/MySQL database integration
